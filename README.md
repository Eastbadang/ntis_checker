# NTIS Checker

국가R&D 기술수요조사서 및 연구 과제의 사전 중복성을 검토하고 유사 과제를 점검하기 위한 분석 도구 모음입니다.

NTIS(국가과학기술지식정보서비스) 오픈 API 연동 모듈과 수요조사서 문서 자동 분석 및 판정 GUI 도구로 구성되어 있습니다.

---

## 주요 모듈 구성

본 저장소는 크게 두 가지 핵심 디렉터리로 나뉘어 있습니다:

* **[ntis_api/](./ntis_api)**
  * NTIS 국가R&D 검색 및 연관 콘텐츠 조회 API 클라이언트 모듈
  * 과제·논문·특허·보고서 데이터 수집, 필터링, 결과 데이터 보강(Enrichment) 파이프라인 제공
* **[survey_checker/](./survey_checker)**
  * PySide6 기반의 수요조사서 중복성 점검 데스크톱 GUI 프로그램
  * HWP, HWPX, DOCX, PDF, TXT 형식의 제안 문서를 파싱하여 기술명·키워드·목표·내용 자동 추출
  * 유사도 기반 판정(유지 / 개선 / 불가) 및 검토 보고서 자동 생성

---

## 시작하기

### 1. 요구 사항

- Python 3.11 ~ 3.13 권장
- NTIS 오픈 API 인증키 (공식 NTIS 포털에서 발급 및 IP 사전 승인 필요)

### 2. 설치 및 실행

각 모듈 디렉터리로 이동하여 필요한 라이브러리를 설치하고 실행합니다.

```bash
# 수요조사서 점검 GUI 실행 예시
cd survey_checker
pip install -r requirements.txt
python survey_checker_gui.py
```

# 보안 및 데이터 관리 원칙 (Security & Privacy)   

본 프로젝트는 연구 기획 및 분석 편의를 위해 설계되었으며, 오픈소스 공개 및 사용 시 아래의 보안 원칙을 준수합니다:   

## 1. 인증키 분리 및 비공개

NTIS API 인증키 및 접속 정보는 소스코드에 하드코딩되지 않으며, 환경변수(.env) 또는 사용자 로컬 설정(settings.json)을 통해서만 로드됩니다.   

저장소에는 실제 키 파일이 포함되어 있지 않으며, 예시 파일(settings.example.json 등)만 제공됩니다.   

## 2. 사내 기밀 및 개인정보 보호

분석을 위해 입력된 문서 원문 전체는 외부 서버로 일괄 전송되지 않으며, 검색에 필요한 핵심 기술명 및 키워드만 추출되어 API 요청에 사용됩니다.

수집된 원본 응답 파일(search_out/, *.jsonl, *.csv)은 참여 연구자 성명 등 개인정보를 포함할 수 있으므로 .gitignore를 통해 Git 추적 대상에서 제외됩니다.

samples/ 디렉터리 내 예시 데이터는 모두 가상의 텍스트로 구성되어 있습니다.

## 3. 결과 활용에 대한 고지

본 도구가 제공하는 중복성 및 유사도 판정 결과는 텍스트 유사도 알고리즘에 기반한 1차 사전 검토용 참고자료입니다.

최종 과제 선정 및 중복성 판정은 발주 부처 및 전담기관 연구심의위원회의 정식 심의 기준에 따릅니다.
