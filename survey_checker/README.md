# 수요조사서 중복성 점검

수요조사서 파일을 끌어다 놓고 **[점검하기]** 한 번이면, NTIS와 KISTI 기준DB에서 비슷한 과제를 찾아 **유지 / 개선 / 불가**를 판정하고 고칠 점을 알려줍니다.

## 사용법 (3단계)

1. **파일 놓기**: 수요조사서(HWP·HWPX·DOCX·PDF·TXT)를 창에 끌어다 놓습니다. 여러 건이면 [일괄 양식 받기]로 받은 양식에 채워서 놓습니다.
2. **점검하기**: 버튼을 누르면 NTIS에서 과제·논문·특허·연구보고서를 자동으로 검색하고, KISTI 기준DB와 함께 비교합니다.
3. **결과 확인·저장**: 판정 카드에서 판정과 고칠 점 3가지를 봅니다. [결과 저장]을 누르면 저장 위치와 파일명을 고를 수 있고, Word(.docx)와 .md 파일이 함께 저장됩니다. 여러 건을 점검했다면 요약 CSV도 같이 저장됩니다.

자동으로 나눈 항목(기술명·키워드·목표·내용 등)이 이상하면 [내용 확인·수정]에서 고친 뒤 다시 점검하세요. 상세 결과는 [자세히 보기]에 있습니다.

## 판정 기준

| 판정 | 뜻 | 기본 기준 |
| :--- | :--- | :--- |
| **유지** | 중복 가능성 낮음 | 아래 두 경우가 아님 |
| **개선** | 비슷한 과제가 있어 차별성 보강 필요 | 최고 유사도 0.65 이상, 또는 0.50 이상이 5건 이상 |
| **불가** | 기존 과제와 사실상 겹침, 재기획 필요 | 최고 유사도 0.85 이상 |
| **판단 보류** | 비교 자료 없음 | NTIS 키와 KISTI 기준DB가 모두 없음 |

> **안내**: 기준값은 프로그램 폴더의 `settings.json`에서 `criteria` 값을 수정하여 조정할 수 있습니다. 결과는 텍스트 유사도 비교에 따른 1차 참고자료이며, 최종 판단은 발주기관 연구심의위원회 등에서 진행합니다.

## 처음 한 번만 하는 설정

| 항목 | 방법 |
| :--- | :--- |
| **NTIS 인증키** | `settings.example.json`을 `settings.json`으로 복사하거나, 환경변수 `NTIS_APPRV_KEY=발급키`를 등록합니다. (키는 IP 승인된 PC에서만 동작합니다) |
| **KISTI 기준DB** | [설정]에서 `기준DB_2019_2024_연구과제.csv` 파일 경로를 지정합니다. 비워 두면 프로그램 폴더 주변에서 자동으로 찾습니다. |
| **기본 저장 폴더** | [설정]에서 지정합니다. 마지막으로 저장한 폴더를 기억합니다. |
